# Shared FX

Game-agnostic DOOM-grade combat FX, used identically by every Scourge-universe
game. Visceral, not neon — blood `#c1121f`, hellfire `#ff6a00`, gunmetal, bone.

Placeholder slots (drop the real sprite sheets here):

- `ember-burst.png` — hellfire embers and burn particles.
- `muzzle-flash.png` — weapon muzzle flashes.
