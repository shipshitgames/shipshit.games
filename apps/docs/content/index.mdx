# Welcome

Ship Shit Games builds open studio tooling for making games faster without losing the weird, sharp edges that make the universe feel alive.

These docs explain how to use the packages, apps, and workflows in the studio repo: asset generation, source distillation, shared UI, shared engine code, desktop surfaces, game state, canon rules, and deployment.

## Choose your path

| Path | Use it for | Start |
| --- | --- | --- |
| Studio tooling | Generate assets, distill sources, build UI shells, wire shared packages | [Products](/tools) |
| Game state | Understand what lives in this repo vs. DEADROT and what each game is becoming | [Games](/games) |
| Canon | Keep Scourge, Pyre, Warden, and Deadrot lore consistent across tools and prompts | [Lore](/lore) |
| Deployment | Route `shipshit.games`, `docs.shipshit.games`, and `deadrot.com` cleanly | [Reference](/deployment) |

## Quick start

```bash
bun install
cd apps/docs
bun run dev
```

Open `http://localhost:3001`.

For the main studio site:

```bash
cd apps/web
bun run dev
```
