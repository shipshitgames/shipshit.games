# Getting Started

## Prerequisites

- Bun
- Node-compatible shell
- optional: `yt-dlp` for the ressources transcript path
- optional: provider credentials in the macOS keychain for real image generation

## Install

From the repo root:

```bash
bun install
```

## Run the docs app

```bash
cd apps/docs
bun run dev
```

Local docs run on:

```txt
http://localhost:3001
```

## Build

```bash
cd apps/docs
bun run build
```

## Useful repo checks

```bash
bun run build
bun run typecheck
```
