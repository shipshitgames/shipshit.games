# Lore Primer

The sibling `../lore` repo is the source of truth.

## Locked Scourge contract

- The Scourge is a host-dependent parasite.
- It has no native form; it wears what it infects.
- It is not a generic monster faction.
- It is not evil in the human sense; it optimizes to survive and spread.
- The Choir is the connection, not one killable general.
- Isolation is the human win condition.

## Factions

| Faction | Doctrine |
| --- | --- |
| The Pyre | burn the source |
| The Wardens | hold the line |
| The Listeners | understand the Choir |
| The Scourge | survive and spread |

## Art rule

Toxic green belongs to the Scourge: infection, breach cores, parasite nodes,
and host takeover. Pyre and Warden UI should stay in black, bone, blood red,
hellfire orange, rust, and gunmetal.

## Host families

The Scourge can include many conquered host forms:

- rot-infested flesh hosts
- chitin warhosts
- mycelial spore hosts
- machine-graft hosts
- bone titan hosts
- voidship hosts

Every form still needs the parasite grammar: overwritten host material, rupture
seams, tendrils, breach cores, and invasive growth.
