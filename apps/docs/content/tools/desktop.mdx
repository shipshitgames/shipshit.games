# Desktop Studio

`apps/desktop` is the local studio cockpit.

The desktop app should wrap the same package and CLI surfaces documented here,
not fork their logic.

## Current role

- generator hub for maps, sprites, 3D, music, and SFX
- local Codex-driven production workflows
- future UI wrapper around `assetgen` and `ressources`

## Integration rule

When adding a desktop feature:

1. Put reusable logic in a package.
2. Keep the package callable from a CLI.
3. Let Electron call the package or CLI.
4. Stream logs back to the desktop UI.
5. Register generated outputs in the package manifest with license provenance.
6. Document the command here.

## Asset gallery origin

The desktop Gallery pane reads `../deadrotcom/packages/assets` for offline local
review. Set `ASSET_BASE_URL` to surface the package CDN URL next to each local
asset path:

```bash
ASSET_BASE_URL=https://<cdn-origin>/assets bun run dev
```

The CDN value is metadata for copy/open actions; thumbnails still come from the
local package unless they are missing.

## Dev commands

```bash
cd apps/desktop
bun run dev
bun run typecheck
```
